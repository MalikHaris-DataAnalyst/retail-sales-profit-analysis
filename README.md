# Retail Sales and Profit Analysis

## Project Overview
This is my first Data Analyst portfolio project. I used Python and data analysis techniques to explore retail sales and profit data, identify business problems, and present findings through interactive charts.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Plotly
- GitHub

## Business Questions
- How much sales and profit did the business generate?
- Which product categories generated the most profit?
- Which product subcategories were losing money?
- How were discounts associated with profitability?

## Key Findings
- Total sales were approximately **$2.30 million**.
- Total profit was approximately **$286,397**.
- Technology generated the highest profit among the three product categories.
- Tables, Bookcases, and Supplies had combined losses of approximately **$22,387**.
- Higher discount levels were associated with losses in several parts of this dataset.

## Recommendations
- Review pricing and discount strategies for loss-making products.
- Investigate why Tables, Bookcases, and Supplies are unprofitable.
- Monitor profit margins alongside sales when evaluating business performance.

## Project Files
- `retail_sales_analysis.ipynb` — Python analysis and code.
- `sales_by_category.html` — Interactive sales chart.
- `profit_by_category.html` — Interactive profit chart.

## Limitations
The dataset does not include order dates or order IDs, so this project does not analyze sales trends over time or unique order counts. The findings describe patterns in this dataset and do not establish that discounts alone caused losses.

## What I Learned
I practiced loading data, checking data quality, calculating business metrics, identifying profitability issues, creating visualizations, and communicating findings.
